# ระบบสรุปบทเรียนและคลังข้อสอบเสมือนจริง 120 ข้อ (มสธ. 40101)
## วิชา 40101 ความรู้เบื้องต้นเกี่ยวกับกฎหมายทั่วไป (Introduction to Law)
### มหาวิทยาลัยสุโขทัยธรรมาธิราช (หลักสูตรปรับปรุง)

---

## 📌 จุดเด่นของระบบ (Key Features)

1. **สรุปเนื้อหาเข้มข้นครบทั้ง 15 หน่วยการเรียนรู้ (`js/summary-data.js`)**:
   - เรียบเรียงตามหลักสูตรปรับปรุงของ มสธ.
   - สรุปแนวคิดทฤษฎีสำคัญ (Key Concepts)
   - ไฮไลต์ **"ประเด็นเน้นย้ำชอบออกสอบ" (High-Yield Exam Tips)** ประจำแต่ละหน่วย
   - ช่องค้นหาอัจฉริยะ (Search Filter) ค้นหาคำศัพท์กฎหมาย เช่น *ป.พ.พ. ม.4, Civil Law, จิตวิญญาณประชาชาติ, รัฐธรรมนูญ, ศาลคู่*

2. **คลังข้อสอบเสมือนจริงครบ 120 ข้อ ปรนัย 5 ตัวเลือก (`js/questions-data.js`)**:
   - ข้อสอบ 120 ข้อ ครบ 5 ตัวเลือก (ก, ข, ค, ง, จ) ตามมาตรฐานข้อสอบจริง มสธ.
   - กระจายน้ำหนักตามสัดส่วนข้อสอบจริง: **หน่วยละ 8 ข้อ × 15 หน่วย = 120 ข้อ**
   - มี **เฉลยละเอียด (Detailed Explanations)** อ้างอิงตัวบทกฎหมาย เหตุผล และวิเคราะห์ตัวเลือกทุกข้อ

3. **โหมดจำลองสอบจริง (Exam Simulator Mode)**:
   - จับเวลาถอยหลัง **180 นาที (3 ชั่วโมง)** ตามเวลาสอบจริง
   - แผ่นกระดาษคำตอบดิจิทัล 1-120 ปุ่ม สามารถคลิกข้ามข้อได้ทันที
   - ปุ่ม **"ปักหมุดทบทวน" (Flag for Review)** สำหรับข้อที่ยังไม่มั่นใจ
   - ระบบ Auto-save บันทึกความก้าวหน้าลงในเครื่องอัตโนมัติ (LocalStorage) หากเผลอปิดแท็บสามารถกลับมาทำต่อได้

4. **ระบบประเมินผลและตัดเกรด มสธ. (STOU Grading System)**:
   - คำนวณเกรดตามเกณฑ์ มสธ.:
     - 🏆 **เกรด H (Honor - ดีเด่น)**: คะแนนตั้งแต่ 76% ขึ้นไป (91 - 120 ข้อ)
     - ✅ **เกรด S (Satisfactory - ผ่าน)**: คะแนน 60% - 75% (72 - 90 ข้อ)
     - ⚠️ **เกรด U (Unsatisfactory - ไม่ผ่าน)**: คะแนนต่ำกว่า 60% (0 - 71 ข้อ)
   - **วิเคราะห์จุดอ่อนรายหน่วย (Unit Performance Breakdown)**: กราฟแท่งแสดงคะแนนของแต่ละหน่วย (1-15) ชี้ชัดว่าหน่วยใดที่ควรกลับไปอ่านซ้ำ
   - ตรวจทานคำตอบเทียบกับเฉลยละเอียด กรองดูเฉพาะข้อที่ตอบผิดได้

5. **โหมดฝึกทำโจทย์รายข้อ (Practice Mode)**:
   - เลือกฝึกทำเฉพาะหน่วยที่ต้องการ
   - แสดงผลตรวจและคำเฉลยทันทีที่คลิกเลือก
   - ปุ่ม **"⭐ บันทึกข้อนี้" (Bookmark)** และตัวกรองทำเฉพาะข้อที่บันทึกไว้ หรือข้อที่เคยทำผิด
   - ปุ่มสุ่มข้อสอบสำหรับทบทวนด่วน

6. **รองรับ Responsive & Dark/Light Mode**:
   - ใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
   - สลับโหมดมืด (Dark Mode) ถนอมสายตาขณะอ่านหนังสือตอนกลางคืน

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เว็บแอปพลิเคชันนี้พัฒนาด้วย Standalone HTML5 / CSS3 / Vanilla JavaScript ไม่ต้องติดตั้งโปรแกรมหรือรัน build tools ใดๆ เพิ่มเติม:

### วิธีที่ 1: เปิดไฟล์ตรงผ่านเว็บเบราว์เซอร์
- ดับเบิ้ลคลิกเปิดไฟล์ `index.html` บน Google Chrome, Microsoft Edge, Firefox หรือ Safari ได้ทันที

### วิธีที่ 2: รันผ่าน Local Web Server (ทางเลือก)
เปิด PowerShell หรือ Command Prompt ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
# ใช้ Python
python -m http.server 8080

# หรือใช้ Node.js npx
npx serve
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`
