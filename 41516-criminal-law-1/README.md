# แอปพลิเคชันสรุปบทเรียนและคลังข้อสอบจำลอง มสธ. ชุดวิชา 41516 / 41216 กฎหมายอาญา 1 (Criminal Law 1)

แอปพลิเคชันเว็บแบบ Interactive สมบูรณ์แบบสำหรับการศึกษา ทบทวน และฝึกทำข้อสอบเสมือนจริง สำหรับนักศึกษานิติศาสตรบัณฑิต มหาวิทยาลัยสุโขทัยธรรมาธิราช (มสธ.) ในชุดวิชา **41516 / 41216 กฎหมายอาญา 1: ภาคบทบัญญัติทั่วไป (มาตรา 1 - 106)**

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **สรุปเนื้อหาเข้มข้น 15 หน่วยการเรียน (Comprehensive Summaries)**
   - ครอบคลุม ป.อ. มาตรา 1 - 106 ครบทุกหน่วยการเรียน
   - สรุปแยกประเด็นสำคัญ นิยามศัพท์ องค์ประกอบความผิด และคำพิพากษาฎีกาสำคัญ
   - ไฮไลท์ **จุดเน้นออกสอบบ่อย (High-Yield Tips)** ในทุกหน่วย
   - ระบบค้นหาแบบเรียลไทม์ และตัวกรองแยกตามหน่วย พร้อมปุ่มขยาย/ยุบทั้งหมด

2. **ระบบจำลองสอบปรนัยเสมือนจริง 120 ข้อ (Full Mock Examination)**
   - ข้อสอบแบบปรนัย 5 ตัวเลือก (ก-จ) จำนวน **120 ข้อ** (เฉลี่ย 8 ข้อต่อหน่วย ครบทั้ง 15 หน่วย)
   - ระบบจับเวลานับถอยหลัง 180 นาที (3 ชั่วโมง) เสมือนนั่งสอบจริง
   - แผงกระดาษคำตอบ Interactive Grid แสดงสถานะ: ตอบแล้ว, ยังไม่ตอบ, หรือติดธงทบทวน
   - ระบบประเมินเกรดมาตรฐาน มสธ.:
     - **H (Honor)**: ได้คะแนน ≥ 76% (ตั้งแต่ 92 ข้อขึ้นไป)
     - **S (Satisfactory)**: ได้คะแนน 60% - 75% (ตั้งแต่ 72 - 91 ข้อ)
     - **U (Unsatisfactory)**: ได้คะแนน < 60% (น้อยกว่า 72 ข้อ)
   - กราฟและแท่งวิเคราะห์จุดแข็ง-จุดอ่อนแยกรายหน่วย 1 - 15 (เขียว, ส้ม, แดง)

3. **เวิร์กช็อปฝึกทำข้อสอบอัตนัยปัญหาตุ๊กตา 3 ข้อ (Subjective Essay Workshop)**
   - คัดสรรโจทย์ข้อสอบตุ๊กตามาตรฐาน 3 ข้อ (ข้อละ 20 คะแนน รวม 60 คะแนน):
     - **ข้อ 1 (หน่วย 3-5):** การงดเว้นการกระทำ (ม.59 วรรคท้าย), เจตนาย่อมเล็งเห็นผล, ความสัมพันธ์ระหว่างเหตุและผล (ม.63, ม.290, ม.291)
     - **ข้อ 2 (หน่วย 7-11):** การป้องกันตัว (ม.68), การป้องกันเกินสมควรแก่เหตุ (ม.69), บันดาลโทสะ (ม.72), และการกระทำโดยพลาด (ม.60)
     - **ข้อ 3 (หน่วย 12-14):** พยายามที่ไม่สามารถบรรลุผลได้อย่างแน่แท้เพราะเหตุแห่งวัตถุ (ม.81), ผู้ใช้ (ม.84 วรรคสาม), และผู้สนับสนุน (ม.86)
   - พื้นที่พิมพ์ร่างคำตอบจำลองพร้อมตัวนับจำนวนตัวอักษร และระบบ Auto-Save บันทึกลง LocalStorage
   - **ธงคำตอบมาตรฐาน 3 สเต็ปของ มสธ.:**
     1. หลักกฎหมายที่เกี่ยวข้อง (Statutory Provisions)
     2. การปรับใช้กฎหมายกับข้อเท็จจริง (Subsumption & Analysis)
     3. สรุปผลคำวินิจฉัย (Conclusion)
   - ตารางเกณฑ์การให้คะแนน (Rubrics) แบบ Interactive ให้ผู้เรียนประเมินตนเองตามหัวข้อย่อย

4. **คลังข้อสอบฝึกทำรายข้อ (Practice Mode)**
   - ค้นหาข้อสอบตามคีย์เวิร์ด หรือกรองตามหน่วย
   - เลือกระบบตอบและตรวจเฉลยละเอียดทันที (Instant Feedback)
   - ฟังก์ชันบันทึกข้อสอบที่น่าสนใจ (Bookmark / Starred questions)

5. **สลับรายวิชา มสธ. (Course Switcher)**
   - สลับระหว่าง 41516 กฎหมายอาญา 1, 40101 กฎหมายทั่วไป, และ 10151 ไทยศึกษา ได้อย่างสะดวกรวดเร็ว
   - รองรับ Dark / Light Mode ถนอมสายตา

## 📂 โครงสร้างโฟลเดอร์

```
41516-criminal-law-1/
├── index.html                  # หน้าเว็บหลัก Responsive SPA
├── README.md                   # คู่มือและคำอธิบายชุดวิชา
├── css/
│   └── styles.css              # สไตล์ธีมกฎหมาย Modern Crimson & Slate Legal Theme
├── js/
│   ├── summary-data.js         # ข้อมูลสรุป 15 หน่วยการเรียน
│   ├── essay-data.js           # ข้อมูลโจทย์อัตนัย 3 ข้อ ธงคำตอบ 3 สเต็ป และ Rubrics
│   ├── questions-data.js       # ข้อมูลข้อสอบปรนัย 120 ข้อ (8 ข้อ/หน่วย ครบ 1-15)
│   └── app.js                  # ระบบควบคุมการทำงานตัวจับเวลา และการคำนวณคะแนน
└── generate_questions.py       # สคริปต์ Python ตัวสร้างและตรวจสอบฐานข้อมูลข้อสอบ
```
