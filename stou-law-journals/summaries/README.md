## 🎯 สรุปไฮไลท์ภาพรวมและเทคนิคการสอบ (General Highlights)

### 1. กฎหมายแพ่งและพาณิชย์
* **นิติกรรม สัญญา ละเมิด ทรัพย์สิน**: การตีความเจตนา ความรับผิด ละเมิด ม. 420/437 และสิทธิครอบครอง ม. 1299/1382

### 2. กฎหมายอาญา
* **โครงสร้างความรับผิด 3 สเต็ป**: องค์ประกอบความผิด -> เหตุยกเว้นความผิด (ม. 68) -> เหตุยกเว้นโทษ (ม. 67)

### 3. สูตรเขียนตอบอัตนัย มสธ. (3-Step Formula)
1. **สเต็ป 1**: วางหลักกฎหมาย/มาตรา
2. **สเต็ป 2**: วินิจฉัยปรับบท
3. **สเต็ป 3**: สรุปคำตอบ
